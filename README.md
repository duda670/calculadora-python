# Calculadora em Python

Calculadora de terminal com as quatro operações básicas.

## Como usar

1. Instale o Python 3
2. Rode no terminal: `python calculadora.py`

## O que ela faz

- Soma, subtração, multiplicação e divisão
- Trata divisão por zero e entradas inválidas
- Permite fazer vários cálculos seguidos

## Tecnologias

- Python
